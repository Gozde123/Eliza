## Conversion notes

- **Project Canvas** is left empty. Its canvas grid did not survive text extraction, so the page has only its title. Its subpages were converted in full.
- **Images and embeds** (the example architecture diagram and the Sailboat retrospective board) are not in the source text. Each one has a placeholder line.
- **External links:** the source text kept link labels but lost their URLs. The labels are kept as plain text. Links between pages were rebuilt as relative links.
- **Merged cells** in the Sprint Review form cannot be shown in Markdown. They are approximated with a 4-column table.
- **Numbered tables** (Confluence auto-numbered rows) have a `#` column.
- **Text is verbatim**, typos included (e.g. "Definiton", "seperate", "Plese", "Data Updated:").
